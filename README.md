# B5 Practice

高二英文 Book 5 線上測驗網站，只有兩種功能：

- **單字片語測驗**：按一次「開始測驗」，同一組單字片語**連續**做完三段，中間不回選單，最後一張總成績單
  1. **基礎**：看英文，選出中文意思
  2. **進階**：看中文選英文，加上例句填空四選一（含詞形變化）
  3. **精熟**：沒有選項，看中文拼出英文，加上例句填空拼寫
- **課文理解**：先讀文章，再做閱讀測驗。題目與選項都是改寫過的，不會照抄文章。

學生不用登入，只要填班級、座號和姓名。每次完成整份測驗，成績會送到老師的 Google 試算表（單字片語一次送出一筆，內含三段各自的分數）。老師可以用 Google 帳號登入後台，控制學生看得到哪些單元，以及單字測驗要包含哪幾段。

- 分析與設計說明：[`docs/analysis.md`](docs/analysis.md)
- 目前的單字與文章都是**範例資料**，替換方法請見下方「更換內容」。

## 更換內容

每課有兩個檔案，放在 `data/lessons/`：`lN-voc.json`（單字片語）和 `lN-reading.json`（課文理解）。

**單字片語**

```json
{ "type": "word", "word": "adversity", "pos": "n.", "zh": "逆境；困境",
  "example": "She stayed calm in the face of [adversity].", "exampleZh": "她在逆境中仍保持冷靜。" }
{ "type": "phrase", "word": "bounce back", "pos": "phr.", "zh": "（挫折後）很快恢復",
  "example": "The team [bounced back] after losing the first game.", "exampleZh": "球隊在輸掉第一場比賽後很快重新振作。" }
```

- `type`：單字填 `word`，片語填 `phrase`。出選擇題時，片語的干擾選項也會盡量用片語。
- `example` 裡要考的部分用 `[ ]` 括起來，進階和精熟的例句填空題會挖掉這個部分。括號裡可以是變化形，例如 `[bounced back]`。

**課文理解**

```json
{
  "title": "Mia's Second Try",
  "passage": ["第一段……", "第二段……"],
  "questions": [
    { "skill": "細節", "q": "What went wrong during Mia's first competition?",
      "options": ["…", "…", "…", "…"], "answer": 1, "explain": "第一段：……" }
  ]
}
```

- `answer` 是正確選項的索引，從 0 開始。
- `skill` 是題型標籤，例如主旨、細節、字義、推論、態度。

改完後執行內容檢查：

```bash
node tools/check-content.mjs
```

檢查項目：

- 課文理解的題目或選項，只要跟文章有**連續 6 個英文字以上相同**，就算照抄，會列為錯誤；連續 5 個字會列為警告。
- 單字片語的例句有沒有用 `[ ]` 標出目標字、有沒有重複的字，以及中文意思有沒有重複。

換成真正的內容後，記得把 `data/lessons/index.json` 裡對應單元的 `"sample": true` 拿掉，並更新 `count`。

## 發布到 GitHub Pages

1. GitHub repo → **Settings → Pages** → Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`。
2. 網址會是 `https://<帳號>.github.io/<repo>/`。
3. 在原本的 Google Sites 用「插入 → 嵌入 → 依網址」貼上這個網址，或把導覽連結改到新網站。

## 老師後台與成績（Google Apps Script）

1. 開啟（或建立）一份 Google 試算表 → **擴充功能 → Apps Script**。
2. 把 `apps-script/Code.gs` 的內容貼進預設的 `程式碼.gs`（先刪掉原本的內容）。按左側「檔案」旁的 **＋ → HTML**，命名為 `Admin`，貼上 `apps-script/Admin.html`。按 **儲存**。
3. 上方函式選單選 `setup`，按 **執行**，依畫面授權。執行後會建立 `settings`、`teachers`、`scores`、`content` 四個分頁，並把你的帳號加入老師名單。其他老師的帳號可以直接加到 `teachers` 分頁。
4. **部署 → 新增部署作業 → 類型選「網頁應用程式」**：執行身分選「我」，誰可以存取選「所有人」，按 **部署**。
5. 把 Web App 網址（結尾是 `/exec`）貼到 `js/config.js` 的 `SCRIPT_URL`，然後 commit。
6. 老師用學校 Google 帳號登入後，打開同一個網址（不帶參數）就是後台。這個網址也會出現在網站頁尾的「老師後台」連結，以及試算表上方的「B5 Practice → 開啟老師後台」。

> 如果部署時「誰可以存取」沒有「所有人」可選，代表學校網域限制了對外存取：學生必須先登入學校 Google 帳號才能送出成績。可以改用個人 Gmail 建立試算表來避免這個限制。

老師可以設定：

| 設定 | 效果 |
| --- | --- |
| 顯示 | 取消勾選後，學生首頁就看不到這個單元 |
| 包含的階段 | 單字片語連續測驗要包含哪幾段（例如取消精熟，就只考基礎 → 進階）；課文理解可以整個關閉 |
| 每段題數 | 單字片語每一段的題數（預設 10 題，三段共 30 題） |

### 在後台匯入單字與文章

後台的「**匯入內容**」分頁可以直接替換任何一個單元的內容，不用改程式：

- **單字片語**：從 Excel 或 Google 試算表選取「英文、詞性、中文、例句、例句翻譯」這幾欄，複製後貼上。也可以自己打字，每行一個，用 `|` 隔開。例句裡要考的部分用 `[ ]` 括起來，沒括的話系統會自動找出來；含空格或詞性寫 `phr.` 的會當成片語。
- **課文理解**：貼上文章（段落之間空一行），再逐題填題目、四個選項、點選正確答案、寫解析。
- 按「**預覽與檢查**」：會列出每一行的狀態。缺欄位、例句找不到目標字、重複的字、少於 4 個、沒選正確答案，或是題目照抄文章（連續 6 個字以上），都要修正後才能儲存。
- 按「**儲存到網站**」：內容存進試算表的 `content` 分頁，學生網站約 1 分鐘內更新，首頁的「範例」標記也會消失。
- 「**載入目前內容**」可以把網站內建的題目載入表單再修改；「**還原成網站內建內容**」會刪除匯入的版本。

如果學生網站讀不到試算表（例如網路問題），會自動改用網站內建的內容。

### AI 出題（Google Gemini）

「匯入內容」分頁可以用 Gemini 幫忙出題：

- **課文理解**：貼上文章後按「**AI 產生題目**」（可選 3–10 題），會產生涵蓋主旨、細節、字義、推論、態度的選擇題、正確答案和中文解析，並填進下方表單。題目和選項會要求改寫；如果照抄文章，系統會自動請 AI 重寫一次，之後還會再跑一次防照抄檢查。
- **單字片語**：只輸入英文（每行一個）後按「**AI 補齊詞性、中文與例句**」，會補上詞性、中文、用 `[ ]` 標好的例句和例句翻譯。已經填好的行不會被改動。
- AI 只是先幫你填好表單，**一定要老師逐題確認後**才按「儲存到網站」。

設定方式：

1. 到 [Google AI Studio](https://aistudio.google.com/apikey) 登入，按「Create API key」。學校帳號無法申請時，請改用個人 Gmail。免費額度有次數限制，用完要等一段時間才能再用。
2. 在後台「匯入內容」→「AI 設定」貼上金鑰並儲存。金鑰存在 Apps Script 的指令碼屬性裡，學生網站看不到。
3. 第一次使用 AI 時，Google 會要求新增「連接外部服務」的權限：請到 Apps Script 編輯器執行一次 `setup` 並按允許，然後在「部署 → 管理部署作業」建立新版本。
4. 模型預設為 `gemini-2.5-flash`；如果 Google 之後更換模型名稱，在「AI 設定」改成新的名稱即可。

`scores` 分頁的欄位：時間、班級、座號、姓名、單元、階段、分數、總分、百分比、基礎、進階、精熟（各段得分，例如 `9/10`）、錯題、作答秒數。
「練習錯的題目」只是讓學生複習，不會送出成績。

> 帳號判斷使用 `Session.getActiveUser()`，學校 Google Workspace 網域內的帳號可以取得 email。修改 Apps Script 程式碼後，要在「管理部署作業」建立新版本才會生效。

## 專案結構

```
index.html               入口（hash 路由：#/u/<單元>）
css/style.css            配色與版面
js/app.js                首頁、單元頁、路由
js/nav.js                導覽列「選擇單元」下拉選單
js/levels.js             三段的出題規則
js/modes/vocab.js        單字片語三段連續測驗
js/modes/reading.js      課文理解流程
js/components/*.js       題目元件（選擇題、字母框拼字）、結果頁、測驗前關卡
data/lessons/*.json      課程資料
tools/check-content.mjs  內容檢查（防止閱讀題照抄文章）
apps-script/             Google Apps Script：Code.gs（成績、設定、初始化）＋ Admin.html（老師後台）
```
