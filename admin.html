到 Google AI Studio 登入後按「Create API key」，把金鑰貼在下面。金鑰只存在這份試算表的 Apps Script 裡，學生看不到。學校帳號無法申請時，請改用個人 Gmail。
每行一個單字或片語，欄位順序：英文、詞性、中文、例句、例句翻譯（可省略）。
從 Excel 或 Google 試算表選取這幾欄直接複製貼上即可；也可以自己打字，用 | 隔開。
例句中要考的部分用 [ ] 括起來，例如 The team [bounced back] quickly.；沒括的話會自動找出來。含空格或詞性寫 phr. 的會當成片語。
同一個字可以放不只一句例句：在例句欄用 ; 隔開幾句（例句翻譯欄也用 ; 對應隔開），學生每次考這個字的例句題會隨機抽一句，不會每次都一樣。
已經填好的行不會被改動；多加例句是額外補在原本的例句後面。
題目與選項請用自己的話改寫，不要照抄文章：和文章連續 6 個英文字以上相同會無法儲存，連續 5 個字會提醒。
會取代下方目前的題目；產生後請逐題確認再儲存。

匯入學生名單

每行一位學生：座號　姓名（用 Tab、空白或逗號隔開，可從試算表直接複製兩欄貼上）。學生要輸入跟名單完全一樣的班級、座號、姓名才能登入。重複匯入同一位學生不會產生重複資料。

查詢／刪除單一學生資料

轉學、畢業，或學生（家長）要求刪除個人資料時使用。會刪除這位學生在 Firestore 的所有紀錄：登入帳本、每次測驗作答、檢討狀態；不影響試算表裡的成績（成績另外用「學期結算」或後台試算表本身刪除）。請先查詢確認是這位學生，再刪除，動作無法復原。

⚠ 刪除單元的所有紀錄

會刪除這個單元的所有紀錄：單元本身（設定、匯入的題目、代號）、試算表成績（scores、details、班級分頁、成績單欄位）、Firestore 的作答與檢討紀錄。學生網站上也會立刻消失，無法復原。建議先到下方建立成績備份。這個功能預設關閉，要輸入管理者設定的通關密語才能使用。
