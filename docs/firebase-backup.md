# Firebase 備份與保護設定（Blaze 方案）

題目只存在 Firestore（`public/content_<單元>`），成績也以 Firestore 為正本，所以要開備份。
以下都在 Google Cloud Console 操作（用專案擁有者帳號登入），每項做一次就好。專案 ID：`eng-3385e`。

## 1. 時間點還原（Point-in-time recovery，PITR）

可以把資料讀回過去 7 天內任何一分鐘的樣子（例如誤刪題目後，讀回刪除前一分鐘的內容）。

1. 打開 <https://console.cloud.google.com/firestore/databases?project=eng-3385e>
2. 點 `(default)` 資料庫 → 左邊「災難復原」（Disaster recovery）
3. 「時間點復原」→「編輯」→ 勾選啟用 → 儲存

費用：保留 7 天的舊版本資料，以目前資料量每月不到 1 美元。

## 2. 每日自動備份

每天一份完整備份，保留 14 週（整個學期）。誤刪後超過 7 天才發現，就靠這個。

1. 同一頁「災難復原」→「備份」→「建立排程」
2. 頻率選「每天」，保留期間選「14 週」→ 建立

費用：備份儲存空間每 GB 每月約 0.03 美元；目前資料量遠小於 1 GB。

需要還原時：「備份」列表 → 選日期 →「還原」，會還原成一個**新的資料庫**（不會蓋掉現在的），確認內容後再把需要的資料搬回來。這一步請找我幫忙寫搬回的程式。

## 3. 防止刪除資料庫

避免有人（或誤操作）把整個資料庫刪掉。

- `(default)` 資料庫頁面 →「編輯」→ 開啟「刪除保護」→ 儲存

## 4. 預算快訊

用多少付多少的方案，設一個提醒，用量異常時會寄信給你（只提醒、不會停用服務）。

1. 打開 <https://console.cloud.google.com/billing/budgets>
2. 「建立預算」→ 專案選 `eng-3385e` → 金額填 3 美元（約 NT$100）
3. 快訊門檻保留 50%、90%、100% → 完成

## 已經自動做的

- **老師名單**：只在試算表 `teachers` 分頁維護，Apps Script 自動同步到 Firestore `admins` 與 Realtime Database `staff`，不用再到 Firebase 主控台加人。
- **操作紀錄**：後台儲存題目、刪除題目、刪除單元、刪除學生、學期清除、修改 AI 設定、同步老師名單，都會記在試算表 `audit` 分頁（時間、帳號、動作、對象）。
- **學期備份**：後台「建立成績備份」複製整份試算表時，會把各單元題目從 Firestore 補進備份檔的 `content` 分頁。

Realtime Database 只放即時在線人數與每小時統計，不需要備份。
